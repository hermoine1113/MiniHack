You need Docker in **Questions 1, 2 and 3**. Question 4 (AWS EC2) does not specifically require Docker.

The important thing is that each question uses Docker differently.

## **1. Where exactly do you use Docker?**

**Q1. Docker Compose**

Docker required

Run an existing web application image together with a MySQL container.

- Create `docker-compose.yml`.
- Use the web application image from Docker Hub.
- Use the official MySQL image.
- Start both containers using `docker compose up -d`.
- Verify using `docker ps`.

**Q2. Jenkins CI/CD**

Docker required

Build your Java application and turn it into a Docker image.

- Get the OLTRS repository.
- Create a `Dockerfile` if one doesn't already exist.
- Jenkins builds and tests using Maven.
- Jenkins creates a Docker image.
- Jenkins pushes the image to your Docker Hub.

**Q3. Kubernetes / Minikube**

Docker image required

Deploy the image you pushed to Docker Hub in Q2.

- Create a Kubernetes Deployment YAML.
- Create a Service YAML.
- Deploy your Docker Hub image.
- Scale to four replicas.
- Access the application using Minikube.

**Q4. AWS EC2**

Docker not required

- Launch EC2.
- Install Java, Maven and Tomcat.
- Clone the repository.
- Build and deploy the application on Tomcat.

## **2. Do you need to create a Dockerfile inside the repository?**

**Only for Q2 if the repository doesn't already contain one.**

For example, your OLTRS repository should look something like this:

**OLTRS/**

&#x20;src/

&#x20;pom.xml

&#x20;Dockerfile&#x20;

Create if missing



&#x20;Jenkinsfile&#x20;

Pipeline script can also be in Jenkins UI



For a Maven project that generates a WAR file and uses Tomcat 9, a basic Dockerfile would be:

```
FROM tomcat:9.0
COPY target/*.war /usr/local/tomcat/webapps/ROOT.war
```

This is only an example. First check whether OLTRS generates a WAR or JAR file. The Dockerfile must match the application's output.

## **3. What should you do first? Follow this order.**

1. **Prepare Docker Desktop**

   Install/open Docker Desktop and check:
   ```
   docker --version
   docker compose version
   docker ps
   ```
2. **Prepare your GitHub repository**

   Fork the OLTRS repository into your own GitHub account:

   [OLTRS GitHub repository](https://github.com/archanareddyse/OLTRS?utm_source=chatgpt.com)

   Then clone your fork:
   ```
   git clone https://github.com/YOUR-USERNAME/OLTRS.git
   cd OLTRS
   ```
3. **Inspect the repository**

   Check whether it contains:
   - `pom.xml`
   - `Dockerfile`
   - Existing application configuration

   Don't create a second Dockerfile if one already exists.
4. **Build and test using Maven**
   ```
   mvn clean test package
   ```
   Check the `target` folder to see whether the output is `.war` or `.jar`.
5. **Create the Docker image**

   After confirming the Dockerfile:
   ```
   docker build -t YOUR-DOCKERHUB-USERNAME/oltrs:latest .
   ```
   Test locally, then push:
   ```
   docker push YOUR-DOCKERHUB-USERNAME/oltrs:latest
   ```
6. **Reuse that image in Q3**

   Your Kubernetes Deployment will use:
   ```
   image: YOUR-DOCKERHUB-USERNAME/oltrs:latest
   ```

## **4. Remember this distinction for the exam**

| Question | File you create/use                | Purpose                              |
| -------- | ---------------------------------- | ------------------------------------ |
| Q1       | `docker-compose.yml`               | Run web app + MySQL                  |
| Q2       | `Dockerfile` + `Jenkinsfile`       | Build and push Docker image          |
| Q3       | `deployment.yaml` + `service.yaml` | Deploy Docker image using Kubernetes |
| Q4       | No Dockerfile required             | Deploy using EC2 + Tomcat            |

**My suggestion:** Start by opening the OLTRS repository and checking whether it has a Dockerfile and whether its Maven packaging is WAR or JAR. That determines exactly what you need to write. Don't start creating files blindly.
