Part 8 – Common troubleshooting questions
These are particularly important because practical examiners often introduce errors deliberately.
Problem	Possible reason	What to do
Docker container exits	Application error	docker logs container
Docker port already allocated	Another process uses port	Change host port
WordPress database connection error	MySQL unavailable or credentials incorrect	Check MySQL logs and network
Database data disappeared	Volume was deleted or not mounted	Verify volume configuration
Jenkins build fails	Compilation or dependency error	Check Console Output
Maven not recognized	Maven not configured	Configure Maven under Tools
GitHub webhook not triggering	Jenkins inaccessible or webhook incorrect	Check ngrok and webhook delivery
Pod stuck Pending	Insufficient resources or scheduling problem	kubectl describe pod POD_NAME
Pod keeps restarting	Application crash or failed health check	kubectl logs POD_NAME
Kubernetes update fails	New image or application problem	kubectl rollout undo deployment/mynginx
Nagios dashboard unavailable	Container stopped or port conflict	docker ps -a, docker logs nagiosdemo
EC2 website inaccessible	Security Group or application port issue	Check inbound rules and container status
SSH connection fails	Wrong key, IP or SSH rule	Check .pem, public IP and port 22

Part 9 – What you should be able to explain without looking at notes
These are the conceptual differences that are easy to confuse.
Comparison	Difference
Docker vs Kubernetes	Docker runs containers; Kubernetes orchestrates them.
Image vs Container	Image is a template; container is a running instance.
Volume vs Container	Volume stores persistent data; container runs the application.
Jenkins vs Maven	Jenkins automates the workflow; Maven builds the Java project.
Build vs Test	Build compiles/packages; test checks application correctness.
WAR vs JAR	WAR is commonly used for Java web applications; JAR packages Java applications/libraries.
Deployment vs Service	Deployment manages Pods; Service provides network access to them.
Scaling vs Self-healing	Scaling changes replica count; self-healing replaces failed Pods.
Rolling update vs Rollback	Rolling update introduces a new version; rollback restores an earlier version.
Host vs Service in Nagios	Host is a machine; service is something monitored on that machine.
WARNING vs CRITICAL	WARNING indicates a concern; CRITICAL indicates a serious failure.
EC2 vs CloudWatch	EC2 provides computing; CloudWatch monitors resources and applications.
Public IP vs Private IP	Public IP enables external access; private IP is used within private networks.
SSH vs HTTP	SSH provides secure remote administration; HTTP serves web traffic.
